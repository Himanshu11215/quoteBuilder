# Quote Builder

A simple web tool that generates quotes based on a user-provided topic.

## ✨ Features

- Enter a topic
- Click "Generate"
- Instantly get a quote related to the topic

## 🔧 How It Works

1. Open the website.
2. Type in a topic (e.g., "success", "life", "motivation").
3. Click the **Generate** button.
4. A quote related to that topic will appear.
